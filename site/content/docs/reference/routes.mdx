title: HTTP routes
description: Every route the handler serves under basePath, with its method, who may call it, and what it does.

`helpdesk.handler(request: Request): Promise<Response>` serves every route below under `basePath` (`/api/helpdesk` by default). Paths match with or without a trailing slash; the widget and the agent UI request them with one. Ids are UUIDs. Request and response bodies are JSON unless a row says otherwise. Related guides: [Receive email](/docs/guides/inbound-email), [Run jobs and retention](/docs/guides/jobs).

<Callout type="warn">
  The `widget/*` and `agent/*` routes are the contract between the handler and the widget and agent UI that ship with it. They can change in any minor release and are not an API for other callers. Host code calls the helpdesk through the functions `buildHelpdesk` returns, as in [Call the helpdesk from your own code](/docs/guides/own-code). `inbound`, `jobs` and `rate` are the routes meant for callers outside the package.
</Callout>

```ts title="app/api/helpdesk/[...slug]/route.ts"
import { helpdesk } from '@/lib/helpdesk';

const handle = (request: Request) => helpdesk.handler(request);
export { handle as GET, handle as POST, handle as PATCH, handle as PUT, handle as DELETE, handle as OPTIONS };
```

## Callers

| Caller | How the handler knows them | Routes |
| --- | --- | --- |
| Customer | `identify(request)`; else, when `identityTokenSecret` is set, an `x-helpdesk-identity` token signed with it; else an `x-helpdesk-visitor` token | `widget/*` |
| Agent | `identify(request)` returning `isAgent: true`. 401 without an identity, 403 when it is not an agent | `agent/*` |
| Email link | The signature in the query string | `rate` |
| Mail relay | `Authorization: Bearer {inboundWebhookSecret}` | `inbound` |
| Scheduler | `Authorization: Bearer {jobsSecret}` | `jobs` |

A visitor token is issued by `POST widget/conversations` to an anonymous visitor, and stops working after 30 days unused. An invalid identity token is refused with 401.

A customer **can see** a conversation they opened, one they were added to as a participant, and one shared with a company the caller's identity lists in `orgs`. A conversation they cannot see answers 404. Routes marked **author** also require the caller to be the conversation's own contact, and answer 403 otherwise.

## Widget

| Method | Path | Caller | What it does |
| --- | --- | --- | --- |
| `GET` | `widget/session` | Anyone | The caller's state: whether they are identified, name, email, organizations, conversations with previews, the configured types, whether help search is on, recent agents, team name, away and opening times, and the settings' confirmation text. With `?inbox=`, that inbox's title, reply promise, privacy URL, qualifying question and booking URL. `?locale=` picks the language. For an agent, the count of waiting conversations and a link to the agent UI. |
| `POST` | `widget/conversations` | Customer, or an anonymous visitor on a `public` inbox | Opens a conversation. Answers 201 with `{ conversation: { id, reference }, visitorToken? }`. See [the body](#opening-a-conversation). |
| `GET` | `widget/conversations/{id}` | Can see | The conversation in the customer's terms, its public messages and its attachments. |
| `POST` | `widget/conversations/{id}/messages` | Can see | Adds `{ body }`, 1 to 20,000 characters. Answers 201 with `{ id }`; 404 when the contact is blocked, 409 when the conversation was merged, 429 over the rate limit. |
| `PATCH` | `widget/conversations/{id}` | Author | `{ sharedWithCompany?: boolean, status?: 'resolved' }`, at least one. Sharing needs the conversation's company to be one the caller belongs to: 400 when it has none, 403 otherwise, 409 when an agent moved it meanwhile. Answers `{ ok: true }`. |
| `POST` | `widget/conversations/{id}/rating` | Author | `{ rating: 'good' \| 'bad', comment?: string }`, comment up to 2,000 characters. 409 when the conversation is not open for a rating. |
| `POST` | `widget/conversations/{id}/seen` | Can see | Marks the conversation read by its author. |
| `POST` | `widget/conversations/{id}/attachments` | Author | Starts an upload: `{ filename, contentType, size }`, with `filename` 1 to 200 characters, `contentType` one of the [allowed types](/docs/reference/adapters#storage) and `size` a positive integer in bytes. Answers 201 with `{ id, upload: { url, fields } }`. 400 without `storage`, 413 over `maxAttachmentBytes`, 429 past 20 attachments or over the rate limit. |
| `POST` | `widget/conversations/{id}/attachments/{attachmentId}/complete` | Author | Marks the upload done; 409 when the object is not in storage. |
| `GET` | `widget/conversations/{id}/attachments/{attachmentId}` | Can see | 302 to a presigned download URL. |
| `GET` | `widget/help` | Anyone | `?q=` (first 200 characters) and `?locale=`. Answers `{ results }`, at most five `HelpResult`s; empty without `help`. |

## Agent

Every route here requires an agent.

| Method | Path | What it does |
| --- | --- | --- |
| `GET` | `agent/me` | The agent, and the configuration the agent UI needs: reference prefix, types, statuses, priorities, inbox keys, names and hours, lead and deal stages, custom fields, qualifying answers, whether AI is set. |
| `PATCH` | `agent/me` | `{ awayUntil: string \| null }`, an ISO timestamp with offset. |
| `GET` | `agent/settings` | `{ confirmation }`: what the widget says after a first message, per locale. |
| `PUT` | `agent/settings` | `{ confirmation: { en?, de? } }`, each up to 1,000 characters. `{email}` and `{reference}` are filled in. |
| `GET` | `agent/overview` | New and resolved counts and the median first response and resolution times, in total, per inbox and per agent; ratings and the 10 most used tags in total. Times count open hours for inboxes with `hours`. `?days=7`, `30` (default) or `90`. |
| `GET` | `agent/unread` | `{ waiting }`: the count of waiting conversations. |
| `GET` | `agent/tags` | The 15 most used tags. |
| `GET` | `agent/agents` | The team, without removed agents. |
| `DELETE` | `agent/agents/{id}` | Removes an agent from the team and unassigns their conversations. They get no agent mail until they next open the agent UI as an agent. Answers `{ ok: true }`. |
| `GET` | `agent/conversations` | The inbox list with counts, previews and who is viewing each. Filters: `inbox`, `status` (`open`, `pending`, `resolved`, `snoozed`, `rated-bad`, or `any` for all), `assignee` (`me`, `none` or an agent id), `contactId`, `companyId`, `tag`, `q`, `priority=high`, `sort` (`waiting` or `priority`). |
| `POST` | `agent/conversations/bulk` | `{ ids, status?, priority?, type?, inbox?, assigneeId?, snoozedUntil?, addTag? }`, up to 100 ids. 404 with the missing `ids`; 400 with `ids` when `addTag` would take a conversation past 50 tags. |
| `GET` | `agent/conversations/{id}` | The conversation with contact, company, suggested company, host links, customer context, participants, viewers, every message including internal notes, attachments and timeline. Marks it seen by the team. |
| `PATCH` | `agent/conversations/{id}` | `{ status?, priority?, type?, inbox?, subject?, assigneeId?, companyId?, tags?, snoozedUntil? }`. `subject` sets the team's title. `snoozedUntil` must be in the future and makes it `pending`; with another `status`, 400. An unknown `assigneeId` or `companyId` is 400. A new `companyId` ends sharing with the old company. Answers `{ conversation }`. |
| `POST` | `agent/conversations/{id}/messages` | `{ body, internal?, notify? }`: a reply, or an internal note when `internal`. `notify` lists up to 20 agent ids to mention. Answers 201 with `{ id }`. |
| `POST` | `agent/conversations/{id}/participants` | `{ contactId }`: adds a contact to the conversation. |
| `POST` | `agent/conversations/{id}/merge` | `{ targetId }`: merges this conversation into the target. 400 when the target is this conversation or unknown, 409 when already merged. |
| `POST` | `agent/conversations/{id}/draft` | No body: an AI draft reply. `{ mode: 'shorten' \| 'formal' \| 'translate', text }`: a rewrite of the agent's text. Answers `{ text }`; nothing is sent. 400 without `ai`. |
| `POST` | `agent/conversations/{id}/triage` | Runs AI triage now. 400 without `ai`. |
| `POST` | `agent/conversations/{id}/suggestion` | `{ action: 'accept' \| 'dismiss' }` on the stored AI suggestion. 404 when there is none. |
| `GET` | `agent/conversations/{id}/attachments/{attachmentId}` | 302 to a presigned download URL. |
| `GET` | `agent/notifications` | The agent's notifications (assigned, mentioned, replies) and the unread count. |
| `POST` | `agent/notifications/seen` | Marks them read. |
| `GET` | `agent/views` | The agent's saved views and the shared ones, with counts. |
| `POST` | `agent/views` | `{ name, query, shared? }`, `name` 1 to 80 characters, `query` up to 2,000. `query` keeps only `inbox`, `status`, `assignee`, `q`, `tag`, `sort` and `priority`. 409 past 50 views. |
| `PATCH` | `agent/views/{id}` | `{ name }`, 1 to 80 characters. |
| `DELETE` | `agent/views/{id}` | Deletes the view. |
| `GET` | `agent/canned` | The canned replies. |
| `POST` | `agent/canned` | `{ title, body, locale?: 'en' \| 'de' \| null }`. |
| `DELETE` | `agent/canned/{id}` | Deletes a canned reply. |
| `GET` | `agent/contacts` | Contacts. Filters: `q`, `leadStage`, `companyId`. |
| `POST` | `agent/contacts` | `{ name, email?, companyId?, leadStage? }`. |
| `GET` | `agent/contacts/{id}` | The contact with identities, company, host links, conversations, timeline and deals. |
| `PATCH` | `agent/contacts/{id}` | `{ name?, companyId?, leadStage?, tags?, custom?, blocked? }`. |
| `POST` | `agent/contacts/{id}/merge` | `{ sourceId }`: merges that contact into this one. |
| `DELETE` | `agent/contacts/{id}` | Deletes the contact, their conversations, what they wrote elsewhere, and their files. Answers `{ conversations }`, the count deleted. |
| `GET` | `agent/companies` | Companies. Filters: `q`, `leadStage`. |
| `POST` | `agent/companies` | `{ name, domain?, leadStage? }`. |
| `GET` | `agent/companies/{id}` | The company with context, host links, contacts, conversations, timeline and deals. |
| `PATCH` | `agent/companies/{id}` | `{ name?, domain?, leadStage?, tags?, custom? }`. |
| `GET` | `agent/deals` | Every deal with its company and contact names. |
| `POST` | `agent/deals` | `{ title, companyId?, contactId?, stage?, value?, currency?, expectedCloseAt? }`. The caller owns it. |
| `PATCH` | `agent/deals/{id}` | `{ title?, stage?, value?, currency?, expectedCloseAt?, ownerId?, custom? }`. |
| `DELETE` | `agent/deals/{id}` | Deletes the deal. |
| `POST` | `agent/activities` | `{ kind: 'note' \| 'call' \| 'meeting', body, contactId?, companyId?, dealId?, occurredAt? }`, with at least one of the three ids. |

Tags are lower-cased, up to 50 characters each and 50 per record. `custom` values are checked against [`customFields`](/docs/reference/configuration#customfielddef).

## Rate

| Method | Path | Caller | What it does |
| --- | --- | --- | --- |
| `GET` | `rate` | Email link | An HTML page that asks the customer to confirm the rating in the link, with a button. |
| `POST` | `rate` | Email link | Records the rating and answers an HTML page. A `bad` rating opens the conversation again. |

The links come in a [`customer-reply`](/docs/reference/emails#customer-reply). A forged or expired link answers 404. A conversation already rated answers 200 and records nothing; one that is no longer resolved, or was merged, answers 409.

## Inbound

| Method | Path | Caller | What it does |
| --- | --- | --- | --- |
| `POST` | `inbound` | Mail relay | Takes one raw message (`message/rfc822`) as the body and checks DKIM. Signed mail from the conversation's contact or a participant is added to the conversation that its `In-Reply-To` or `References`, or a `+{reference}` recipient address, points to. Any other mail opens a conversation in `inboundInbox`. Answers 202 with `{ ok: true }`. |

Without `inboundWebhookSecret`, or with another bearer token, it answers 401. The message is refused with 400 when empty, and with 413 over 25 MiB or when its headers exceed 64 KiB. Mail from a blocked address, and unsigned automated mail (an out-of-office or a bounce), is accepted with 202 and not stored; signed automated mail that answers a conversation is stored there as an internal system note. A message already stored, by Message-ID, is accepted and ignored. Signed mail from a sender over their hourly budget answers 429; unsigned mail over budget is dropped quietly.

## Jobs

| Method | Path | Caller | What it does |
| --- | --- | --- | --- |
| `POST` | `jobs` | Scheduler | Runs `helpdesk.runJobs()` and answers its report. |

Without `jobsSecret`, or with another bearer token, it answers 401.

`runJobs({ budgetMs }: { budgetMs?: number } = {})`, with `budgetMs` 20,000 by default, wakes due snoozes, queues due reminders, applies `retentionDays`, then works through due jobs until the budget is spent. It returns:

<TypeTable
  type={{
    woken: { type: 'number', required: true, description: 'Snoozed conversations reopened.' },
    reminders: { type: 'number', required: true, description: 'Reminders queued.' },
    retention: { type: 'number', required: true, description: 'Conversations deleted by retention.' },
    jobs: { type: 'number', required: true, description: 'Jobs completed.' },
    failed: { type: 'number', required: true, description: 'Jobs that threw.' },
    errors: { type: 'string[]', required: true, description: <>The steps that failed: <code>wake</code>, <code>reminders</code>, <code>retention</code>.</> },
  }}
/>

A failed job runs again after 2, 4, 8 and 16 minutes, and is kept with its last error after the fifth attempt. The job kinds are on [Database](/docs/reference/database#job).

## Origins and CORS

- A mutation is any method but `GET`, on any route but `rate`, `inbound` and `jobs`. A `POST` mutation must send `Content-Type: application/json` (415 otherwise).
- A mutation that carries an `Origin` header must come from the origin of `adminUrl`, or, on a `widget/*` route, from an origin in an inbox's `allowedOrigins`. Otherwise it answers 403.
- `widget/*` responses to an allowed origin carry CORS headers: methods `GET, POST, PATCH, OPTIONS`, headers `content-type, x-helpdesk-visitor, x-helpdesk-identity`, max age 600 seconds. Agent routes never do.
- `OPTIONS` on any path answers 204.

## Errors

| Status | Body |
| --- | --- |
| 400 | `{ error: 'Invalid request', issues }` for a body that fails validation, where `issues` lists the paths of the invalid fields; `{ error: 'Invalid JSON' }` for a body that does not parse; otherwise `{ error }`. |
| 404 | `{ error: 'Not found' }` for an unknown route or a record the caller may not see. |
| 413 | `{ error: 'Too large' }` for a JSON body over 256 KiB or an inbound message over 25 MiB; `{ error: 'File too large' }` for an upload over `maxAttachmentBytes`; `{ error: 'Headers too large' }` for inbound headers over 64 KiB. |
| 500 | `{ error: 'Internal error' }`; the error is logged. |
| Other | `{ error, ids? }`, where `ids` lists the conversations a bulk change failed on. |

## Limits

| Limit | Value |
| --- | --- |
| Anonymous conversations, messages and uploads, per IP address (IPv6 per /64) | `anonymousRateLimit` an hour, 20 by default |
| Signed-in customer's conversations, messages and uploads | `customerRateLimit` an hour, 60 by default |
| Receipts | 200 an hour |
| New-conversation notices to agents | 200 an hour, each for host users and for everyone else |
| AI triage | 100 an hour, each for host users and for everyone else |
| Inbound email per sender address | 30 an hour, signed and unsigned counted apart |
| Inbound email per sender domain | 100 an hour, signed and unsigned counted apart; a signed reply from someone on the thread is not counted |
| Message length | 20,000 characters |
| JSON body | 256 KiB |
| Inbound message | 25 MiB |

Over a customer limit, the route answers 429. Over the receipt, notice and triage caps, the conversation is stored and the email or triage is skipped.
